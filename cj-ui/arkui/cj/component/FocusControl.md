### Method (Static)
- `requestFocus(value: String)` — requests focus by id
- `clearFocus()` — clears current focus
- `getFocus(): String` — gets the current focused component id
- `setAutoFocus(...)` / `setFocusable(...)` etc. — focus strategy settings
