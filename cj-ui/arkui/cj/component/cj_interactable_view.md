# Interaction events (cj_interactable_view)

Interaction event type collection definitions: touch/click/key/mouse/drag events and their strategies and results.

---

## Event types
- `TouchEvent` — touch event
- `ClickEvent` — click event
- `KeyEvent` — key event
- `MouseEvent` — mouse event
- `DragEvent` — drag event
- `TouchTestInfo` — touch test info
- `TouchResult` — touch test result

## Data Structures
- `TouchObject` — touch object
- `DragInfo` / `DragItemInfo` — drag info/drag item

## Enums
- `DragBehavior` — drag behavior
- `DragResult` — drag result
- `PreDragStatus` — pre-drag status
- `TouchTestStrategy` — touch test strategy
