# Engine 仓库说明：

`fork from https://gitcode.com/arkui-x`

Engine仓库是基于ArkUI-X仓库优化拓展，可构建支持在鸿蒙、Android和iOS设备上运行的UI Engine程序，并且支持仓颉UI前端和三方UI前端。

# Engine 仓目录结构

``` bash
Engine/
├── build/                           # 引擎的构建脚本文件夹
├── foundation/                      # 基础设施相关文件夹
├── test/                            # 测试文件夹
├── utils/                           # 公共库文件夹
├── build.sh                         # 构建脚本
└── ...
```
