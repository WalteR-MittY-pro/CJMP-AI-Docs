# 贡献文档

非常欢迎您贡献文档，我们鼓励开发者通过 GitCode Issue 反馈文档问题和改进建议。



## 贡献方式

### 反馈文档问题

高质量的问题反馈有助于我们不断完善文档内容和质量，您提供的信息越详尽，对我们问题改进越有帮助。

1.  进入 Docs 仓库的 GitCode Issue 页面，单击“新建 Issue”。
2.  根据问题类型选择合适的模板：
    - Bug（问题反馈）：用于文档错误、失效内容、链接异常、排版问题等反馈。
    - Enhancement（新需求/改进）：用于新增文档、补充说明、结构优化等建议。
    - Question（问题咨询）：用于文档内容理解、使用方式等咨询类问题。
3.  按模板要求填写标题和详细内容，尽量补充问题描述、复现步骤、期望结果、实际结果、环境信息等。
4.  单击“创建”按钮提交 Issue，耐心等待文档团队成员确认和处理。
