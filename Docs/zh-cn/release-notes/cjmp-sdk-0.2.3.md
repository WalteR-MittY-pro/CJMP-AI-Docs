## 1. 文档信息
- **版本号**：v0.2.3
- **发布日期**：2026-05-07
- **作者**：CJMP 团队
- **最后更新时间**：2026-05-12

---

## 2. 版本概述

本次发布聚焦于 适配Android 16KB 内存页大小、组件能力补齐、测试框架稳定性增强和开发调试体验优化。相较于 v0.2.2，新增 WaterFlow、View、Matrix4 等组件支持，完善 Gesture 相关方法与测试能力；升级 Android NDK 至 27.2.12479018 并统一 AGP 8.5.1 配置；IDE 插件支持 macOS 平台下 iOS 真机调试；新增 VibeCoding 仓库，提供 AI IDE 配置、MCP 模板和 Skills 资源。

**版本亮点**：
- 新增 WaterFlow、View、Matrix4 等组件能力，并补齐相关测试用例
- Android 端适配 16KB 内存页大小，统一 NDK 27.2.12479018 与 AGP 8.5.1 配置
- TestFramework 完善多点触控注入、坐标计算、屏幕方向和 Home 键相关能力
- IDE 插件支持 macOS 平台下 iOS 设备真机调试
- 新增 VibeCoding AI IDE 配置资源，支持项目上下文、文档检索和环境配置能力

  - **规避方案**：暂无规避方案，建议以实际编译结果为准。

- Android 端请确保安装 NDK 27.2.12479018，并将 Android Gradle Plugin 升级到 8.5.1 或以上，以满足 16KB 内存页大小适配要求

## 6. 升级指导

### 6.1 升级前准备

1. 备份当前项目代码和配置文件。
2. 确认当前开发环境满足新版本要求（参见 SDK 兼容性说明）。
3. 确认 Android SDK 已安装 NDK 27.2.12479018。
4. 若工程已存在 Android 构建脚本，请确认 Android Gradle Plugin 版本为 8.5.1 或以上。
5. 确保已安装配套的仓颉工具链版本。

### 6.2 升级步骤

1. 从 [SDK 仓](https://gitcode.com/CJMP/SDK)拉取 `v0.2.3` 对应分支，确保 LFS 文件已完整下载。
2. 将环境变量 `CJMP_SDK_HOME` 更新为新的 SDK 目录，并确认 `PATH` 中使用的是新 SDK 下的 `keels`。
3. 执行以下命令检查当前工具版本：

```bash
keels --version
```

4. 执行以下命令检查当前开发环境：

```bash
keels doctor -v
```

5. 如需升级已有 Android 工程，请同步检查工程中的 NDK、AGP、JDK 和模板配置。

### 6.3 升级后验证

1. 编译项目，确保无编译错误
2. 运行单元测试和 UI 自动化测试，验证核心功能正常
3. 在目标平台（HarmonyOS/Android/iOS）上进行功能测试
