# CJMP概览

## 项目介绍

CJMP旨在构建支持UI+逻辑的高性能跨平台开发框架，提高跨平台开发效率，同时提供接近原生的性能体验。 
关键技术特征和技术：
- 高性能跨平台UI框架；
- 高性能逻辑跨平台技术；
- 多UI前端支持；
